# Skills Check 005 — Horizontal Dividers, Borders & Spacing

An interactive HTML and CSS knowledge test for beginners.

## Topics

- HTML `<hr>` and thematic breaks
- CSS border width, style, color, and shorthand
- Solid, dashed, dotted, and double borders
- Margin and padding
- The CSS box model
- Reading and understanding CSS declarations
- Semantic HTML and good styling practices

## Features

- 20 multiple-choice questions
- Random question order on every attempt
- Randomized answer order
- Single-answer and multiple-answer questions
- Instant answer feedback and explanations
- Progress bar
- Final score and percentage
- Restart button
- Responsive layout
- Keyboard focus styles
- Reduced-motion support
- No JavaScript libraries or build tools required

## Getting started

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Answer each question and read the explanations.
4. Review your score and try again if you want.

## Files

- `index.html` — application structure
- `style.css` — design and responsive layout
- `script.js` — questions, randomization, scoring, and navigation
